# فاز ۱۴ — بسته «هویت بصری یادواره + زیرساخت داده + انتشار»
> بریف اجرایی (طراحی پیش از ساخت) — تاریخ تنظیم: ۱۴۰۵/۰۸/۱۹

## اصل نافرهشت هر ۷ کار
1. **هویت‌سنجی پیش از نمایش** — هیچ تصویری بدون برچسب وضعیت کنار نام شهدا/رهبران نمی‌نشیند.
2. **صفر جعل** — تصاویر عملیات فقط از نتایج جست‌وجوی وب با منبع بازنشر می‌شوند؛ هر تصویر «شناسنامه رسانه» دارد.
3. **ادغام، نه چسباندن** — عناصر تزئینی با آلفا گرادیانی و blend به زمینه می‌رویند، نه مستطیل بریده.

---

## کار ۱ — دایپتیک رهبری (بالا-راست: امام، بالا-چپ: رهبری)
- دو پرتره رسمی تازه‌یافته از آرشیو وب، برش عمودی صورت‌محور، کیفیت بالا.
- قاب سبز-طلایی هم‌اندازه با تابلو نام؛ جایگاه ثابت: **امام خمینی (ره) در بالای سمت راست، حضرت آیت‌الله خامنه‌ای در بالای سمت چپ** نوار چهره‌ها (الگوی پوستر یادواره).
- برچسب وضعیت هویت‌سنجی روی هر قاب حفظ می‌شود.

## کار ۲ — روبان «شهید» روی پرتره‌های شهدا
- روبان زرشکی با متن سفید «شهید» بالای هر پرتره شهید در نوار چهره‌های ماندگار (سبک پلاک یادواره) — مطابق درخواست «کلمه شهید به عکس اضافه شود».

## کار ۳ — خاکریز واقعی (تصویر آپلودی کارفرما)
- ورودی: `upload/…سنگر-PNG-4.jpg` (گونی‌شن + آسمان گرادیانی + نشان‌آب FARSGRAPHIC).
- پردازش: حذف نشان‌آب (برش نوار پایین)، جداسازی پس‌زمینه با سگمنتاژ HSV + flood-fill از آسمان، فدر لبه، **آلفا محو در لبه پایین** تا با زمینه یکی شود.
- خروجی: `sandbag-arc.png` (قوس خاکریز شفاف) + `sandbag-strip.png` (نوار قابل تکرار).
- مصرف: زیر hero داشبورد + جایگزینی بافت SVG قبلی در `SandbagStrip` (بافت واقعی، ادغام کامل با زمینه).

## کار ۴ — پرچم ایران در زمینه + گیف موج‌دار
- رندر `flag-iran.svg` → PNG، تولید انیمیشن موج پارچه (۲۶ فریم، حلقه بی‌پایان) → `public/images/flag-wave.gif`.
- ادغام در زمینه: نسخه کم‌رنگ (opacity ~0.10) به‌عنوان لایه پس‌زمینه hero داشبورد + گیف موج‌دار واقعی در کنار عنوان hero؛ پرچم تعاملی گوشه تصویر دست‌نخورده می‌ماند.

## کار ۵ — گالری تصاویر عملیات‌ها + عکس کلی شهدا
- پوشش: فتح‌المبین، بیت‌المقدس، رمضان، خیبر، بدر، والفجر ۸، کربلای ۴، کربلای ۵، مرصاد + موضوع «شهدای دفاع مقدس».
- جست‌وجوی وب (image-search)، دانلود به `public/images/ops/<op-id>/`، ثبت در `media-registry` با منبع/مجوز/اصالت و opIds — نمایش خودکار در پرونده عملیات، آرشیو و گالری.

## کار ۶ — ارتقای پایگاه داده مرورهای کارشناسی
- مدل `MazarReview` در Prisma/SQLite (هم‌ساختار با API فعلی): photoKey یکتا، verdict چهارحالته، reviewer، note.
- بازنویسی `/api/reviews` روی Prisma با **fallback فایل** (سازگاری نسخه نمایشی بدون DB) + اسکریپت مهاجرت یک‌باره `db/mazar-reviews.json` → جدول.
- نتیجه: مرورهای کارشناس از مرورگر مستقل می‌شوند (رفع کامل P2 گزارش منتقد).

## کار ۷ — ریزاصلاحات باقی‌مانده + انتشار
- `favicon.ico` واقعی (مشتق از نشان پرچم) + تنظیم ارتفاع/فاصله سربند برای رفع کراپ عمودی تیکر.
- **انتشار:** پوش دادن کل پروژه به GitHub + ورک‌فلو GitHub Actions (`windows-latest`) برای ساخت **exe قابل‌حمل ویندوز** با معماری Electron + Next standalone؛ نسخه‌گذاری و پیوست به Release.
- محدودیت قفل‌شده: لینک مستقیم «خاک سرخ» هرگز تغییر نمی‌کند؛ صدای TTS با افشا می‌ماند؛ هیچ تصویر ساختگیِ جعلی مجاز نیست.
